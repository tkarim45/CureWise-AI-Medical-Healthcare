CureWise — Architecture

A personal AI health companion: one account, a set of self-serve tools that help a user understand their health calmly, then point them toward professional care. It informs; it does not diagnose.

Feature-first backend

  • • each feature is router.py + service.py + schemas.py under features/
  • • chat (RAG) · medical_report (LlamaParse) · disease_detection (7 models)
  • • skin (acne vision) · emergency (nearby hospitals) · profile · medical_history
  • • single `user` role — no hospital, doctor, admin or appointment features

Models + providers

  • • OpenAI gpt-4o-mini for chat, embeddings and report structuring
  • • Groq llama-3.3-70b / llama-4-scout for per-disease chat and skin vision
  • • RAG on Pinecone with text-embedding-3-small (1536-dim)
  • • 7 Keras/TensorFlow image models, lazily loaded and cached

Adding a model is a data change

  • • specs.py holds key, weights path, input size, labels, optional chat prompt
  • • so a new image model needs no new endpoint code
  • • routes: list · /{disease}/classify · /{disease}/chat
  • • every AI result carries a persistent disclaimer: informs, does not diagnose
